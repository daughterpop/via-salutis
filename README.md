# Via Salutis

Catholic fasting, prayer, and a household rule — so the body can be what it already is: a temple of the Holy Spirit.

Sister site of [Via Fidelitatis](https://www.viafidelitatis.com).

## Stack

TanStack Start (file-based routing) + Tailwind CSS v4. Deployed on Vercel.

## Local

```bash
npm install
npm run dev
```

## Pages

- `/` home
- `/fasting` liturgical fasting calendar
- `/essays` short essays
- `/ember` Sunday letter
- `/shop` affiliate products (disclosed)
- `/faq` and `/about`
